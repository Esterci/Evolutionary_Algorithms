# Final results

This directory stores the final CSV summaries generated by
`../de_rand_1_bin_adpt.py`.

Each file represents one experimental configuration. Every independent run is
appended as a new row containing its seed, objective-function budget, best
objective value, best decision vector, final adaptive-parameter statistics,
the shared constraint penalty weight, the percentage of feasible individuals
in the final population, and corresponding evolution-curve path. The reported
best solution is the lowest-objective feasible individual. If no feasible
individual exists, the lowest penalized-fitness individual is reported as an
explicit fallback with `is_feasible=False`.
Repeating the experiment appends new rows; it does not remove rows from previous
executions. If a legacy result file has a different schema, the new results are
written to a compatible sibling file.
