# Final results

This directory stores the final CSV summaries generated by
`../de_best_1_bin_adpt.py`.

Each file represents one experimental configuration. Every independent run is
appended as a new row containing its seed, objective-function budget, best
objective value, best decision vector, final adaptive-parameter statistics,
and corresponding evolution-curve path. Repeating the experiment appends new
rows; it does not remove rows from previous executions.
