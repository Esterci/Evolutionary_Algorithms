# Evolution curves

This directory stores convergence curves generated by
`../de_best_1_bin_adpt.py`.

Each CSV file represents one seeded execution and its filename identifies that
seed. The file contains:

- `seed`: random seed;
- `fitness_evaluations`: cumulative objective-function evaluations;
- `fit_mean`: mean fitness of the current population; and
- `fit_std`: population standard deviation (`unbiased=False`) of fitness.

The first row describes the initialized population. Intermediate rows follow
the configured evaluation step, and the last row describes the population at
the exact evaluation budget. The associated final summary is stored in
`../results/`.
